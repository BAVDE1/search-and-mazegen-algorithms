# search-and-mazegen-algorithms

various maze generation and search algorithm demonstrations.

uses openGL for rendering & glfw for the window. (so rendering may be unstable on other devices)

supports windows and linux.

### Maze-gen

* random depth first
* random kruskai
* random prim
* wilson (not implemented yet)
* recursive division
* fractal tesselation

### Searching

* depth first
* breadth first
* greedy best first
* a star
